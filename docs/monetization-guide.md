### 1.1 赚钱原理

```
用户搜索 "best AI video editor" → 进入你的 Review 文章 → 点击 Affiliate 链接 → 购买工具
→ Affiliate 平台记录转化 → 佣金进入平台账户 → 你提现到 PayPal → PayPal 提现到银行卡
```

### 1.3 重要：W-8BEN 税表

申请美国公司的 Affiliate 时，平台会要求填 **W-8BEN 表**。

| 项目 | 内容 |
|------|------|
| 是什么 | 声明你是非美国税务居民 |
| 为什么要填 | 不填会被扣 30% 美国预扣税 |
| 填什么 | 姓名、国家（China）、声明自己是中国税务居民 |
| 在哪填 | 平台后台有电子表格，在线勾选即可 |
| 结果 | 税率降为 0%（中美有税收协定） |

## 二、Google AdSense

### 2.1 赚钱原理

```
Google 在你的网页上投放广告 → 访客浏览/点击广告 → Google 按展示量结算 → 每月自动电汇到你银行卡
```

### 2.2 收入模型

| 月 PV | RPM（千次展示收入）| 月收入 |
|------|-------------------|--------|
| 1,000 | $10 | $10 |
| 5,000 | $10 | $50 |
| 20,000 | $15 | $300 |
| 100,000 | $20 | $2,000 |

> RPM 取决于流量来源国。美国流量 ≈ $20-30，印度流量 ≈ $1-3。SEO 做英文内容 = 流量以美国/欧美为主 = RPM 较高。

### 2.3 需要注册

| 步骤 | 内容 |
|------|------|
| 网址 | adsense.google.com |
| 账户类型 | 个人（Individual） |
| 需要信息 | Google 账号、网站 URL、收款银行卡信息 |
| 审核时间 | 2-4 周 |
| 何时申请 | **月 PV 到 5000+ 时再申请**。太早没意义，一个月 $10 还不够折腾 |

### 2.4 完整到账链路

```
访客浏览你的网页 → 看到/点击广告
     │
     ▼
AdSense 后台累积收益（实时显示）
     │
     ▼
每月 1-3 号结算上月收益
     │
     ▼
收益 ≥ $100 才会触发付款（不够就滚存到下月）
     │
     ▼
每月 21 号左右 Google 自动电汇
     │
     ▼
国内银行卡收到美元 → 银行自动结汇为人民币入账
     │  (可能有 $10-15 中间行电汇费)
     ▼
到账
```

### 2.5 AdSense 收款需要的银行卡信息

在 AdSense 后台添加付款方式时需要填写：

| 字段 | 内容 |
|------|------|
| 账户持有人姓名 | 拼音（与银行卡一致）|
| 银行名称 | 英文（如 China Merchants Bank）|
| SWIFT/BIC 代码 | 问银行客服要 |
| 账号 | 银行卡号 |
| 开户行地址 | 银行英文地址 |
