# Quality Gate

Every article must pass ALL 11 checks before handoff to user. No exceptions.

---

## 🚨 强制门禁：bash 校验脚本

**唯一交付前置条件**：必须跑这个脚本，并把完整输出贴出来：

```bash
bash scripts/article-check.sh <path-to-mdx-file>
```

- 退出码 `0` → 通过，可交付
- 退出码 `1` → FIX，修复后重跑
- 退出码 `2` → REWRITE，重写

**没贴脚本输出 = 违反红线 6.5，文章直接退回。** 不接受任何理由（"我看过了"/"应该没问题"/"显然通过"全部无效）。

脚本会自动校验下面 11 项：

---

## 11 Hard Checks（脚本会自动跑这些）

Run the script and show the output. Never claim "done" without evidence.

### Check 1: Required Sections Present
- Review: `## Key Features`, `## Pricing`, `## FAQ`
- Compare: `## At a Glance`, `## Pricing`, `## Who Should Choose`, `## FAQ`
- Blog: `## ` (at least one H2), `## FAQ`
Expected: every required section returns present.

### Check 2: No Placeholders
Scans for: `Other Tool`, `Varies by tool`, `TBD`, `TODO`, `implement later`, `fill in`
Expected: NO OUTPUT. Any match = FAIL.

### Check 3: Pricing Table Specificity
Must NOT contain generic names like `Tool A`, `Tool B`, or `Other Tool` in pricing tables.
Expected: Pricing table uses actual tool names from frontmatter.

### Check 4: FAQ Count
Counts bold-question lines (`**Question?**`).
Expected: ≥3 FAQ entries.

### Check 5: Word Count
Expected:
- Review: ≥800 words
- Compare: ≥600 words
- Blog: ≥800 words

### Check 6: No Corrupted Headings
Scans for `##.*##` pattern (merged headings on same line).
Expected: NO OUTPUT. Any match = corrupted headings, fix immediately.

### Check 7: Internal Links + Visual Elements
- Internal links: ≥2 (to `/reviews/`, `/compare/`, `/blog/`, `/categories/`)
- Images: ≥1 (`![...](/logos/...)`)
- No forbidden React components (`<WinnerBadge>`, `<ProsCons>`, `<ScoreCard>`, `<CTABox>`)
Expected: All three sub-checks pass.

### Check 8: SEO Frontmatter
- Title: 30-70 chars (review type generates dynamically if `title:` not set)
- Description: 110-165 chars
- All image alt texts: ≥15 chars each
- Compare type: title/description check skipped (generated by `generateMetadata`)

### Check 9: lastUpdated ISO 8601
Format: `2026-06-04T12:53:58Z`
Expected: Present and valid ISO 8601 format. **No lastUpdated = article won't sort correctly on listing pages. Auto-FAIL.**

### Check 10: Schema-Ready Frontmatter
> **防止 frontmatter 数据喂给 page.tsx 后生成无效 JSON-LD Schema（Google 会整页 reject）。**
- Review: `pros` array ≥ 3 items (ensures `ratingValue: 4.6`, not 4.3)
- Review: `pricing` is one of: `Free`, `Freemium`, `Paid` (determines `offers.price`)
- Review: `tags` array is non-empty (ensures review category data completeness)
- Blog: `author` field is consistent (unified as "ToolPorto Team")
- All: `date` / `lastUpdated` use ISO 8601 or `YYYY-MM-DD` (parsed by `new Date()` into valid ISO)

### Check 11: AI Writing Patterns
Two sub-checks, both must pass:

**11a: Vocabulary** — 45-word AI pattern list (aligned with anti-ai-patterns-en.md).
Scans for: `actually`, `additionally`, `align with`, `arguably`, `comprehensive`, `crucial`, `delve`, `effectively`, `emphasize`, `empower`, `enduring`, `enhance`, `essentially`, `fostering`, `fundamentally`, `garner`, `highlight`, `holistic`, `in today's`, `in conclusion`, `interplay`, `intricate`, `intricacies`, `it's important to note`, `leverage`, `multifaceted`, `notably`, `nuanced`, `paradigm`, `pivotal`, `remarkably`, `seamless`, `showcase`, `significantly`, `streamline`, `tapestry`, `testament`, `to summarize`, `in summary`, `underscore`, `undoubtedly`, `unlock`, `valuable`, `vibrant`, `noteworthy`.
Expected: 0 hits. Any match = flagged for rewrite.

**11b: Em dash density** — Body text (excluding frontmatter) em dash count per 100 words.
anti-ai-patterns-en.md Pattern 6: "AI overuses — like this — constantly."
Expected: ≤1.0 em dashes per 100 body words. Exceeding = rewrite with commas, periods, or restructure.

## 🚨 额外强制要求：Build 通过

脚本不检查 build（太慢），但 **build 必须通过才能交付**：

```bash
npm run build 2>&1 | tail -5
```

Expected: "✓ Compiled successfully" or build exits 0 without errors.
**Build 不通过 = 退回修复，与脚本分数无关。**

## Scoring

| Score | Status | Action |
|-------|--------|--------|
| 11/11 | ✅ PASS | Hand off to user |
| 8-10/11 | ⚠️ FIX | Fix issues, recheck, hand off |
| ≤7/11 | ❌ REWRITE | Major issues, rewrite the article |

## 3-Role Self Review

After passing all 11 checks + build, run this mental review:

### Role 1: SEO Expert
- Does the title match a real search query someone would type?
- Is the primary keyword in H1, first 100 words, and at least one H2?
- Would this page rank for the target keyword?

### Role 2: Reader
- After reading, do I know which tool to choose?
- Was the article worth my time, or did I skim and leave?
- Does it feel like a person wrote it, or a marketing department?

### Role 3: Devil's Advocate
- Give 1 strong reason why someone should NOT follow this article's recommendation.
- If that reason can't be countered → the article needs revision.
- Example: "You say DeepSwapper is best for quality, but you didn't mention it only supports front-facing portraits."

**If Devil's Advocate wins → go back to writing (Phase 2) and add the counter-argument.**

---

## Fix-Then-Recheck Workflow

```
Check fails → fix the specific issue → recheck THAT check → rerun full script → confirm 11/11 → hand off
```

Never fix a failing check and hand off without rechecking.
Never explain away a failure ("it's probably fine"). Evidence or fail.
