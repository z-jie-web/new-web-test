## 二、域名购买流程

### 1. 域名选择原则

你当前站点方向是海外 AI 视频工具导航 / 评测 / 推荐站，所以域名建议遵守：

优先原则：
- 优先 `.com`
- 尽量简短
- 易拼写
- 避免连字符过多
- 不要过度堆关键词
- 不要碰商标风险明显的名称

推荐风格：
- 品牌型：
  - 例如：aivideohub.com 这类
- 品牌 + 轻关键词型：
  - 例如：getaivideohub.com
  - 例如：aivideoguidehub.com

不建议：
- 太长
- 多个连字符
- 明显蹭大品牌商标
- 纯生硬关键词堆砌

### 2. 购买域名时看什么

重点看：
- 首年价格
- 续费价格
- 是否送 Whois 隐私保护
- DNS 管理是否方便
- 后续转移是否容易

你当前阶段不需要追求“高价极品域名”，买一个正常、干净、可用的 `.com` 就够了。

### 3. 域名购买后要记录的东西

买完后你至少要保留：
- 域名注册平台账号
- 域名本身
- DNS 管理入口
- nameserver / DNS 配置入口位置
- 到期时间

最好单独记到一个安全笔记中，避免后面忘记续费或找不到 DNS 入口。

## 三、上线前最终替换项

在正式绑定域名后，你需要对当前站点做一次“统一替换”。

### 必改项

1. 全站 canonical
当前还是 `example.com` 占位。
必须统一换成真实域名。

2. Open Graph / URL 相关字段
如果页面里有 `og:url` 或类似字段，也要统一替换。

3. `robots.txt`
里面的 sitemap 地址必须换成真实域名。

4. `sitemap.xml`
所有 URL 必须换成真实域名。

5. 联系邮箱
如果 contact 页面里还是：
- contact@example.com
- partnerships@example.com
需要换成你真实可接收邮件的邮箱。

### 建议同步检查项

- About 页里的品牌描述
- Footer 里的站点名是否统一
- 页面 title / meta description 是否都符合英文站调性
- 是否还存在其他占位信息

## 四、Vercel 部署流程

### 方案定位

你这个项目非常适合：
- GitHub + Vercel 自动部署

这是最稳妥、最适合长期更新的方式。

### 推荐部署方式

#### 方式 A：GitHub 连接 Vercel（推荐）

流程：
1. 把 `E:/webTest` 放进一个 GitHub 仓库
2. 登录 Vercel
3. 选择 “Import Project”
4. 连接 GitHub 仓库
5. 让 Vercel 自动识别为静态站
6. 完成首次部署

优点：
- 以后更新只要 push 代码
- Vercel 自动重新部署
- 更适合长期运营

#### 方式 B：手工上传 / 拖目录（不太推荐）

只适合一次性测试，不适合长期维护。

### 在 Vercel 上应如何配置

你的站当前是纯静态多 HTML 站，所以原则上：
- 不需要复杂 build 命令
- 不需要 Node 项目框架配置
- 不需要后端服务

只要 Vercel 把仓库识别为静态输出即可。

### 首次部署后必须验证的页面

上线后优先打开这些地址：
- `/`
- `/index.html`
- `/categories/video-generation.html`
- `/categories/face-swap.html`
- `/tools/sora.html`
- `/tools/topaz-video-ai.html`
- `/use-cases/ecommerce-ads.html`
- `/about.html`
- `/contact.html`
- `/privacy.html`
- `/disclaimer.html`
- `/404.html`
- `/robots.txt`
- `/sitemap.xml`

### 部署后重点检查的内容

1. 页面是否能打开
2. CSS 是否加载正常
3. 分类页链接是否正常
4. 工具详情页是否正常
5. use-case 页是否正常
6. 没有路径错乱
7. 广告位是否仍然隐藏
8. 手机端是否排版正常
9. 外链按钮是否正常新窗口打开
10. 404 页面是否可访问

## 五、域名绑定流程

### 1. 在 Vercel 中添加自定义域名

在 Vercel 项目设置中添加你的正式域名，例如：
- yourdomain.com
- www.yourdomain.com

### 2. 在域名注册商处配置 DNS

通常需要做的是：
- 按照 Vercel 提示添加 A 记录或 CNAME
- 等待解析生效

注意：
- 有时几分钟生效
- 有时可能要几小时
- DNS 生效前不要误判“网站挂了”

### 3. 绑定后要验证的内容

域名生效后检查：
- 裸域能否打开
- `www` 能否打开
- 是否自动统一到你希望的主域
- HTTPS 是否正常签发
- 页面资源是否都正常加载

### 4. 主域选择建议

建议只统一保留一个主域版本，例如：
- `https://yourdomain.com`
或
- `https://www.yourdomain.com`

然后全站 canonical、sitemap、robots 都统一到这个版本。

不要两个版本混着用。

## 七、Google Search Console 提交流程

### 为什么一定要做

如果你的第一目标是 SEO 引流，Search Console 基本是必须的。
因为它能告诉你：
- 有没有抓取
- 有没有收录
- 哪些页面有 impressions
- 哪些词带来曝光
- 哪些页面 CTR 低

### 建议流程

1. 域名正式可访问后，登录 Google Search Console
2. 添加你的网站属性
3. 优先推荐添加“域名属性”
4. 按要求做 DNS 验证
5. 验证成功后提交 sitemap

### 提交 sitemap 后看什么

主要看：
- sitemap 是否被成功读取
- 已发现 URL 数量
- 已收录页面数量
- 是否有抓取问题

### 上线初期的心态

不要期待刚提交就立刻出流量。
新站前几天甚至前几周没有明显展示是正常的。
重点是：
- 能否被抓取
- 是否逐步进入索引

## 八、GA4 是否现在就要接

### 结论
可以接，但不是硬性第一优先级。

如果你希望更早观察页面访问，可以接。
如果你当前想先把 Search Console 跑起来，也可以先不急。

### 建议顺序
优先级建议：
1. 先域名
2. 先部署
3. 先 Search Console
4. 再 GA4

### GA4 主要作用
- 看页面访问量
- 看停留情况
- 看流量来源
- 看哪些页被用户真实浏览

这对后续广告位恢复、内容加码会有帮助。

## 九、AdSense 相关的正确节奏

### 当前策略是对的

现阶段先隐藏广告位，是对的。
原因：
- 网站前期内容还在养
- 审核前露出空广告框会伤害体验
- 站点看起来更像正常内容站

### 不建议现在就做的事
- 不要急着恢复广告位
- 不要让页面像“纯导流+等广告审核”的站

### 更合理的节奏

1. 先上线
2. 先收录
3. 先持续补内容
4. 站点像正常内容站后
5. 再逐步恢复广告位并申请审核

## 十、上线后前 7 天要做什么

- 检查手机端

- 检查是否有漏改的 example.com
- 补一轮小文案和小内链
- 观察是否有基础抓取迹象

## 十一、上线后前 30 天要看什么

重点观察：
- 哪些页面最先被抓取
- 哪些页面最先出现 impressions
- 哪些页面完全没信号
- 哪些标题可能 CTR 偏低
- 哪些分类 / 工具方向更值得继续扩

最重要的不是立刻赚钱，
而是看这个站有没有开始形成：
- 抓取
- 收录
- 展示
- 可继续扩展的内容方向

## 十二、后续什么时候才考虑改架构

### 现阶段不改
现在不建议改。

### 什么时候该认真考虑改
当满足以下情况时：
- 页面数上升到 100~150+
- 你明显感觉手工改 HTML 太累
- 你要大量新增 guides / compare / alternatives / news
- 同一个模板每次都要改很多页面

### 那时建议的方向
- 优先迁移到静态站点生成器
- 如 11ty 或 Astro
- 仍保持静态输出和 Vercel 托管

### 现在为什么不建议改
因为现在你真正缺的不是“更高级的工程架构”，
而是“真实的搜索引擎信号与运营反馈”。
