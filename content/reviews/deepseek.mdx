DeepSeek is the Chinese AI lab that built its name on open-weight reasoning models, and in August 2026 it shipped its most consequential release yet: DeepSeek V4 Pro. The model went live August 13 on the web, mobile, and API at once, alongside DeepSeek Harness, an open-source agent framework positioned directly against Claude Code. The numbers explain the attention: DeepSWE jumped from 12.8 in the preview to 62.7 in the release, Terminal Bench 2.1 hit 87.9, and DeepSeek claims V4 Pro surpasses Claude Opus 4.8 on several agentic benchmarks. The 1M token context window remains in class. The API, with new peak/off-peak pricing, undercuts US competitors by roughly an order of magnitude.

But benchmarks are not the product. The product is what happens when you sit down and use DeepSeek for daily work: the latency from outside Asia, the content restrictions on certain topics, the rough English localization. V4 Pro is also no longer open-weight like R1 was; the flagship model is API-only, and the open release is the agent framework. This review is about the gap between the numbers and the experience.

## Key Features

- **V4 Pro agent capability** — The flagship upgrade in the August 2026 release. V4 Pro is a 1.6T-parameter MoE model (49B activated per token) built for agent work: native OpenAI Responses API support, a one-click Codex integration script, and thinking-intensity controls (low, high, max, plus non-think mode) that let you trade depth for speed per task. DeepSeek's numbers show DeepSWE at 62.7 (up from 12.8 in the April preview) and Terminal Bench 2.1 at 87.9, which the company says surpasses Claude Opus 4.8 on those runs. For a detailed breakdown of how agent-capable models compare, see our [Best AI Chatbots guide](/blog/best-ai-chatbots).
- **1M token context window, 384K output** — The longest output allowance in class. Claude offers 200K, Gemini offers up to 1M input. DeepSeek's 1M input window with 384K output matters for agent sessions that accumulate long tool-call transcripts and for tasks like feeding an entire codebase into one prompt. If you regularly work with large documents or long agent loops, the context window alone is a reason to keep DeepSeek in your toolkit.
- **DeepSeek Harness, open-source agent framework** — The second half of the August release. Harness is an MIT-licensed, plugin-based agent execution framework positioned as an open-source rival to Claude Code and OpenAI Codex, released as a v0.1 preview. This is where the "open" part of DeepSeek lives now: V4 Pro itself is API-only, but the agent tooling around it is fully open, and some of DeepSeek's benchmark results were produced with Harness in minimal mode.
- **Anthropic-format and OpenAI-format API** — V4 Pro accepts requests through both `https://api.deepseek.com` (OpenAI format) and `https://api.deepseek.com/anthropic` (Anthropic format), with JSON output, tool calls, and dialogue prefix continuation. Model names `deepseek-v4-pro` and `deepseek-v4-flash` replace the legacy `deepseek-chat` and `deepseek-reasoner`, which were discontinued on July 24, 2026.
- **Web search integration** — DeepSeek's chat interface includes a search toggle that pulls real-time web results into responses. Similar to Perplexity's approach but without the citation rigor. Useful for current events and recent data, though the search quality varies and results skew toward Chinese-language sources for some queries.

## Our Take

DeepSeek V4 Pro is the strongest argument yet that Chinese labs can build frontier-adjacent agent models without frontier prices. The August release closed most of the gap with Claude Opus 4.8 on agentic benchmarks: DeepSWE at 62.7, Terminal Bench 2.1 at 87.9, and the company claims V4 Pro surpasses Opus 4.8 on HLE, Terminal Bench, Cybergym, and DeepSWE, approaching Fable 5 on some runs. The 1M context window with 384K output and the native agent API support make it a genuinely viable backbone for coding agents at a fraction of the US price.

But three realities split the audience.

First, latency. DeepSeek's servers are in China. From the US West Coast, API responses average 2-3 seconds, occasionally spiking to 5+ seconds during peak hours. From Europe, 2-4 seconds with similar spikes. Users in Asia get sub-second responses. If your workflow depends on fast, interactive model responses (chat, real-time coding assistance, customer-facing apps), this latency is noticeable and annoying. If your workflow is batch-oriented (overnight evaluations, document processing, async agent runs), it matters much less.

Second, content restrictions. DeepSeek operates under Chinese internet regulations. Queries about Taiwan, Tibet, Xinjiang, Tiananmen Square, Falun Gong, and other politically sensitive topics produce refusal responses or redirects. For most technical and commercial use cases (coding, math, business writing, research), these restrictions are invisible. For journalism, political science, human rights research, and open-ended factual inquiry, they are disqualifying.

Third, the model is no longer open-weight. R1's permissive weights were what made DeepSeek unique; V4 Pro is API-only. The open release this time is Harness, the agent framework, which is genuinely useful but does not give you the model itself. Teams that need self-hosted frontier models should look at [Kimi K3](/reviews/kimi-k3) instead, which kept its weights public.

The question is whether your use case intersects with the restricted topics. If you're generating code, analyzing financial data, or writing documentation, DeepSeek works fine and the restrictions never surface. If you need unfiltered access to all topics, use [ChatGPT](/reviews/chatgpt) or [Claude](/reviews/claude). For teams weighing DeepSeek against Claude on long-form analysis and safety, our [Claude vs DeepSeek comparison](/compare/deepseek-vs-claude) breaks down the trade-offs.

Community response to V4 Pro has been strong but measured, matching the pattern we saw with the R1 release. Developers on [Hacker News](https://news.ycombinator.com) and the [r/LocalLLaMA subreddit](https://reddit.com/r/LocalLLaMA) are mostly testing it inside Harness and Claude Code-style workflows, and the early verdict is that the agent gains are real, the pricing is aggressive, and the reliability in long sessions needs more time to prove out. For STEM-heavy workloads, DeepSeek is genuinely competitive. For writing quality and stylistic control, the US models still lead.

## Pricing Breakdown

The August price change is significant: V4-Pro output went from ¥6 to ¥13.5-¥27 per million tokens, roughly a 2.25x-4.5x increase that analysts read as validation of strong inference demand. Even so, off-peak rates run about a tenth of Claude Opus 4.8 and about 17% of Kimi K3's price; peak rates still undercut Kimi K3 by roughly two-thirds. For teams building on top of LLM APIs, the math is simple: if DeepSeek's quality meets your bar, the cost savings will pay for your infrastructure team. ## Who Should Use DeepSeek

- **Strong fit if you:**
  - Build coding agents and want frontier-adjacent agent benchmarks at a fraction of Claude or Kimi K3 prices — off-peak rates make batch agent workloads genuinely cheap
  - Want an open-source agent framework — Harness (MIT license) is a real Claude Code alternative with model access built in
  - Process high volumes of tokens daily and the ~10x cost difference vs US frontier models is material to your budget
  - Work primarily with technical, scientific, or code-related content where the content restrictions never surface
  - Are based in Asia or your users are, and you benefit from lower latency to China-based servers

- **Not the best if you:**
  - Need the lowest possible latency for real-time, interactive applications and your users are primarily in the US or Europe
  - Require unrestricted access to all topics including politically sensitive ones (use [ChatGPT](/reviews/chatgpt) or [Claude](/reviews/claude))
  - Need open model weights for self-hosting or fine-tuning — V4 Pro is API-only; consider [Kimi K3](/reviews/kimi-k3) for open weights
  - Prioritize creative writing quality and stylistic nuance over raw reasoning capability
  - Want a polished English-language product experience with well-translated docs, error messages, and UI

## FAQ

**Is DeepSeek really free?**
The web and mobile apps give free access to V4 Pro and V4 Flash through the Expert Mode toggle, with web search, file upload, and the full 1M context window. No credit card required. The API has usage-based pricing with peak/off-peak rates.

**How does DeepSeek compare to ChatGPT and Claude on coding?**
V4 Pro is a different animal from the R1-era DeepSeek: it is built for agent work, with native OpenAI Responses API support, a Codex integration script, and DeepSWE at 62.7. On agentic benchmarks DeepSeek claims parity or better against Claude Opus 4.8 on several runs. Claude wins on verified production reliability and writing quality; DeepSeek wins on price. Our [Best AI Coding Tools guide](/blog/best-ai-coding-tools) covers how the coding assistants compare across the full workflow.

**Does DeepSeek's content restriction affect normal use?**
For technical, scientific, and commercial queries, the restrictions are invisible. You can ask about code, math, business strategy, and most everyday topics without hitting a filter. The restrictions apply to politically sensitive topics under Chinese internet regulations. If your work involves journalism, political science, or open-ended historical inquiry, you will encounter refusals that don't exist on ChatGPT or Claude.

**Can I self-host DeepSeek V4 Pro?**
No. V4 Pro is API-only. The open-weight era of DeepSeek (R1 and V3) ended with the July 24, 2026 deprecation of the legacy model names, and the current flagship is not released as weights. What is open now is DeepSeek Harness, the MIT-licensed agent framework. If you need open model weights, [Kimi K3](/reviews/kimi-k3) is the current option.

**Is DeepSeek safe for enterprise use with proprietary data?**
For API usage, DeepSeek's data handling policies should be reviewed by your legal and security teams, particularly regarding data storage and processing in China. For enterprises with strict data residency requirements (finance, defense, healthcare), the absence of a self-hosted flagship model is now a real constraint that R1-era DeepSeek did not have.

**Why is DeepSeek so much cheaper than ChatGPT and Claude?**
Three factors: DeepSeek is a China-based company with lower labor and infrastructure costs, the pricing is denominated in RMB and optimized for the domestic market, and DeepSeek's business model appears to prioritize adoption and ecosystem building over per-token profit. The August 2026 price increase (output went from ¥6 to ¥13.5-¥27 per million tokens) suggests the era of aggressive discounts may be ending as demand catches up with supply.
